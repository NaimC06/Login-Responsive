# 🔐 Login Responsive - AdminExpress

## Descripción del proyecto

Este proyecto consiste en el desarrollo de una interfaz de inicio de sesión responsive, inspirada en un diseño de referencia proporcionado en clase.

La página está desarrollada utilizando **HTML5, CSS3 y Media Queries**, permitiendo que su diseño se adapte automáticamente a diferentes tamaños de pantalla.

## 💻 Características

- Diseño de dos columnas para pantallas de escritorio.
- Panel izquierdo azul con el nombre **AdminExpress**.
- Formulario de inicio de sesión con correo electrónico y contraseña.
- Campos de entrada estilizados.
- Botón de inicio de sesión.
- Enlaces de recuperación de contraseña y registro.
- Diseño responsive para computadoras, tabletas y celulares.
- Ocultamiento automático del panel azul en pantallas de 768 píxeles o menos.

## 🛠️ Tecnologías utilizadas

- **HTML5:** Estructura de la página.
- **CSS3:** Diseño visual y estilos.
- **Flexbox:** Distribución y alineación de los elementos.
- **Media Queries:** Adaptación a diferentes resoluciones de pantalla.

## 🚀 Instalación y ejecución

1. Clonar el repositorio:

```bash
git clone https://github.com/NaimC06/Login-Responsive.git
```

2. Abrir la carpeta del proyecto en Visual Studio Code.
3. Abrir el archivo `index.html` en un navegador como Google Chrome.
4. Cambiar el tamaño de la ventana para comprobar el diseño responsive.

No requiere instalar dependencias adicionales.

## 📱 Funcionamiento responsive

| Dispositivo | Comportamiento |
|---|---|
| Escritorio | Panel azul a la izquierda y formulario a la derecha |
| Tableta (≤768px) | Se oculta el panel azul y se muestra el formulario |
| Celular (≤480px) | Formulario adaptado con espacios y tamaños optimizados |

## 📌 Alcance

El proyecto es una demostración visual del diseño de login. No incluye autenticación real, conexión a base de datos ni almacenamiento de contraseñas.
